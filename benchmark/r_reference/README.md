# R Reference Data

Reference outputs from slidaRtools (R), used as the benchmark standard for the GPU implementation.

## Source

- **R package**: slidaRtools v0.2.0 (author Nikolai Knapp; © 2017 Helmholtz-Zentrum für Umweltforschung GmbH – UFZ)
- **R version**: 4.3.1
- **Input data**: Traunstein 1ha forest inventory (915 trees)
- **Generated by**: `benchmark/run_slidartools.R`

## Parameters

```
make_voxelforest(inv.dt, minx=0, maxx=100, miny=0, maxy=100)
# defaults: vxl_per_sqm=4, stems=FALSE, ground=TRUE, lad_value=1

make_lidarscan(vxf.dt, P0.AGR=0.2, P0.GR=0.2, k=0.2)
```

Note: R's `make_voxelforest` uses `lad_value=1` by default, but the tree inventory has `LAD=0.3` per tree. The Python benchmark uses `lad_value=0.3` to match the R demo workflow which sets `LAD := 0.3` on the inventory.

## Files

| File | Format | Rows | Description |
|------|--------|------|-------------|
| `r_voxelforest.parquet` | Parquet | 263,570 | Voxel forest (X, Y, Z, LAD, LAI) |
| `r_pointcloud.parquet` | Parquet | 37,945 | Simulated LiDAR multi-return point cloud |
| `r_summary_stats.csv` | CSV | 10 | Aggregate metrics |

## Matching Requirements

| Product | Match Type | Criterion |
|---------|-----------|-----------|
| Voxel forest | **Exact** | Jaccard(XYZ) == 1.0, LAD values identical |
| Point cloud | **Statistical** | Distribution shape, Z moments within tolerance |
